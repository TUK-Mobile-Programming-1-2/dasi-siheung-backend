# 시연 가이드

## 1. 시연 데이터 켜기

```bash
./gradlew bootRun --args='--spring.profiles.active=local,demo'
```

- 서버가 시작될 때 시연 계정이 없으면 한 번 만듭니다. 이미 있으면 건너뜁니다. (`DemoDataInitializer`)
- 실제 서비스 흐름(가입 → 등록 → 신청 → 협의 → 승인 → 후기)을 그대로 밟아 만들고, **관리자 검수**와 **지난 이용 기간**만 SQL 로 건너뜁니다.
- **관리자 계정은 만들지 않습니다.** 시연 전에 [관리자 계정 운영 가이드](ADMIN_GUIDE.md) 대로 한 계정을 승격하세요.
- 운영 DB 에는 켜지 마세요. (`prod,demo` 금지 — 실제 이용자에게 시연 공간이 보입니다)

## 2. 시연 계정 (비밀번호 모두 `demo1234!`)

| 이메일 | 이름 | 역할 | 시연 포인트 |
| --- | --- | --- | --- |
| `provider1@demo.dasisiheung.com` | 김정왕 | 공간 제공자 | 정왕역 코너 상가 · 대학가 쇼룸, 확정 예약 1건 |
| `provider2@demo.dasisiheung.com` | 박배곧 | 공간 제공자 | 카페거리 갤러리(**가격 협의 대기**), 공원 앞 상가(검토 중 신청) |
| `provider3@demo.dasisiheung.com` | 이거북 | 공간 제공자 | 마리나 공간, **검수 대기 공간 1곳**, 1:1 대화 |
| `user1@demo.dasisiheung.com` | 최팝업 | 이용자 | 찜 2곳, 가격 제안 보낸 신청, 커뮤니티 모집 글 |
| `user2@demo.dasisiheung.com` | 정전시 | 이용자 | 졸업 작품 전시 확정 예약 |
| `user3@demo.dasisiheung.com` | 한클래스 | 이용자 | 공원 앞 클래스 신청(검토 중) |
| `user4@demo.dasisiheung.com` | 오체험 | 이용자 | 마리나 팝업 신청, 제공자와 1:1 대화 |

공개 공간 5곳에 지난 이용 후기 5개(평점 4~5)와 답글이 있고, 월별 통계에도 반영되어 있습니다.

## 3. 시연 순서 (약 10분)

`http/demo-scenario.http` 를 위에서부터 실행하면 아래 흐름이 그대로 재현됩니다.

1. **둘러보기** — 비로그인으로 지도 · 검색 · 추천(브랜드 홍보 → 카페거리 · 대학가가 위로)
2. **신청** — 최팝업 로그인 → 마리나 공간에 가격 제안과 함께 신청
3. **협의 · 확정** — 이거북 로그인 → 역제안 → 최팝업 수락 → 이거북 승인 (겹치는 신청 자동 마감)
4. **소통** — 오체험 ↔ 이거북 1:1 대화 (폴링)
5. **관리자** — 대시보드 → 검수 대기 공간 승인 → 신고 처리 → 월별 통계
