# 개인정보 보관 · 파기 기준

서비스가 다루는 개인정보와 언제 지우는지 정리합니다. 파기는 매일 04:30(KST) 자동으로 실행되고,
관리자 웹에서 미리보기 후 바로 실행할 수도 있습니다. (`/api/v1/admin/privacy/*`)

## 1. 보관 기간

| 정보 | 보관 | 기간이 지나면 | 설정 (환경 변수) |
| --- | --- | --- | --- |
| 회원 이메일 · 이름 · 휴대폰 | 탈퇴할 때까지 | 탈퇴 즉시 `withdrawn-{id}@deleted.invalid` · "탈퇴한 회원" 으로 바꾸고 휴대폰 삭제 | - |
| 신청서 글 (활동 이름 · 계획 · 거절/취소 사유), 가격 제안 한마디 | 이용 종료 후 **365일** | `(파기됨)` 으로 비식별화. 날짜 · 금액은 정산 기록으로 남김 | `PRIVACY_APPLICATION_RETENTION_DAYS` |
| 1:1 대화 · 메시지 | 마지막 메시지 후 **365일** | 대화 통째로 삭제 | `PRIVACY_CONVERSATION_RETENTION_DAYS` |
| 활동 전후 사진 | 이용 종료 후 **90일** | 기록과 저장소 파일 삭제 | `PRIVACY_ACTIVITY_PHOTO_RETENTION_DAYS` |
| 리프레시 토큰 | 만료까지 (14일) | 매일 04:00 삭제 | `JWT_REFRESH_TOKEN_VALIDITY` |
| 공간 권한 증빙 | 공간을 지울 때까지 | 비공개 버킷, 관리자 · 제공자만 10분짜리 임시 주소로 열람 | - |
| 이용 후기 · 커뮤니티 글 | 작성자가 지울 때까지 | 공개 게시물. 신고 처리 시 숨김 | - |

검토 중(PENDING)인 신청과 아직 통계에 들어가지 않은 확정 예약은 비식별화하지 않습니다.

## 2. 통계 보존

비식별화 전에 확정 예약을 **월 · 지역 · 활동별 건수 · 이용 일수 · 금액**으로 `monthly_usage_stat` 에 더합니다.
누가 · 무엇을 했는지는 남기지 않고 수치만 남겨, 지역 상권 활성화 효과를 계속 보여줄 수 있게 합니다.
(`GET /api/v1/admin/statistics/monthly`)

- 한 예약은 한 번만 더해집니다 (`space_application.counted_in_stats`). 파기를 여러 번 실행해도 결과가 같습니다.

## 3. 실행 기록

실행할 때마다 `privacy_purge_log` 에 기준일과 처리 건수, 실행한 관리자(자동이면 비움)를 남깁니다.
(`GET /api/v1/admin/privacy/purge-logs`)
